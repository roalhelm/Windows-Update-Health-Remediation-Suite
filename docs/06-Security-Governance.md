# Security und Governance

- PowerShell-Code reviewen und signieren.
- Least Privilege für Verwaltung und Deployment.
- Keine Secrets oder personenbezogenen Daten im Scriptoutput.
- Logs mit angemessener ACL und Retention betreiben.
- Repair Source nur read-only und authentisiert bereitstellen.
- Hash/Version von Medien dokumentieren.
- Pilot, Change, Rollback und Wartungsfenster verpflichtend.
- EDR-Ausnahmen nicht pauschal setzen. Blockaden zunächst über Audit-/Vendor-Analyse klären.
